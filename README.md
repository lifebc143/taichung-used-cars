## 現在的車

## 怎麼加一台車

在 `index.html` 複製一組 `<article class="car">...</article>`，換上新車的車款、里程、售價、配備與連結即可。

## 照片

照片放在 `images/` 資料夾，檔名 `ux250h-01.jpg` 到 `ux250h-12.jpg`，網頁會自動顯示。照片請用 GitHub 網頁上傳（把照片拖進 `images/` 資料夾），Muse 的 GitHub 推送只接受文字檔、傳不了圖片。
